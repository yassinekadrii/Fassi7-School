6. DATABASE & SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
* Framework: Next.js 16 (Turbopack, App Router) + React 19 + TypeScript.
* Database: SQLite via better-sqlite3 (fassi7.db) with 13 relational tables:
  1.  users               (Staff accounts & directory records with role-based access)
  2.  teaching_languages  (Languages catalog with Arabic, French, and English descriptions)
  3.  courses             (Curriculum, CEFR levels, format, tuition, duration, and trilingual content)
  4.  course_teachers     (Many-to-many course to teacher assignments)
  5.  teacher_profiles    (Teacher bios, qualifications, specialties, and hourly rates)
  6.  student_profiles    (Student personal information, city, and learning objectives)
  7.  enrollments         (Student course registrations, pipeline status, and tuition balances)
  8.  class_sessions      (Calendar schedule of class sessions and virtual room links)
  9.  attendance          (Session-level attendance records)
  10. payment_receipts    (Official receipts, payment methods, transaction references)
  11. contact_inquiries   (Website contact form leads and placement inquiries)
  12. notifications       (Internal activity feed)
  13. audit_logs          (Security audit trail recording administrative actions)

* RESTful API Endpoints:
  - /api/auth/*          (Login, logout, session check, quick-switch demo)
  - /api/courses/*       (Course CRUD, search, and duplication)
  - /api/languages       (Language CRUD and catalog)
  - /api/enrollments     (Enrollment applications and status transitions)
  - /api/payments/*      (Payment logging and receipt generation)
  - /api/staff/*         (Secretary account creation and management)
  - /api/students        (Student directory records)
  - /api/teachers        (Faculty directory records)
  - /api/schedule/*      (Calendar sessions and attendance sheet logging)
  - /api/inquiries       (Contact inquiries pipeline)
  - /api/reports         (Aggregated analytics)
